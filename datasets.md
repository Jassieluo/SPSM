# Datasets

Download all datasets, including the supplementary test set, from [Baidu Netdisk](https://pan.baidu.com/s/11CErw77QGsR4ggeV6_2a2A?pwd=bw2k).

- **RS-AOD:** COCO and YOLO formats.
- **ShipRSImageNet:** YOLO format, retaining only the ship category and resizing images to 640 x 640 for the common evaluation protocol.

## Supplementary Test Set

`Real-world_200.zip` contains 200 remote-sensing images (640 x 640) with 1,702 annotated aircraft instances for supplementary evaluation under naturally occurring interference.
