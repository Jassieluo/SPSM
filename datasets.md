# Datasets

Download the datasets used in the paper from [Baidu Netdisk](https://pan.baidu.com/s/11CErw77QGsR4ggeV6_2a2A?pwd=bw2k).

Extraction code: `bw2k`.

- **RS-AOD:** COCO and YOLO formats.
- **ShipRSImageNet:** YOLO format, retaining only the ship category and resizing images to 640 x 640 for the common evaluation protocol.
